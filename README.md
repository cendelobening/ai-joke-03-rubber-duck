# Rubber Duck 2.0

An ai-joke-03 entry about rubber-duck debugging in the age of AI coding agents.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/makefun-output python3 main.py
```

The program writes its single joke to `entry.txt` in the selected output directory. If `MAKEFUN_OUTPUT_DIR` is not set, it uses `/output`.
